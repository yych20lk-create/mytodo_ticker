## 1. 产品是什么

系统托盘常驻的个人效率工具：**无主窗口**。

| 能力 | 说明 |
|------|------|
| 顶栏看板 | 活跃任务标题轮播；左：优先级饼图（色=紧急程度，填充=进度） |
| 任务 | 新建、编辑、进度、完成、废弃；分类、截止、提醒 |
| 周期任务 | 日/周/月自动派发 |
| 番茄钟 | 左：番茄饼图随倒计时填充；右：倒计时或自定义文案 |
| 脚本与服务 | 可选功能：运行本机插件脚本/服务；进度会暂时占用顶栏文字 |
| 闪电添加 | 全局热键快速记待办 |
| AI | 每日计划 + 每日复盘（可分别开关与调度） |
| 通知 | 应用弹窗 + WxPusher（可同时开） |
**习惯：**

- 启动后请看**屏幕顶栏/托盘**，不要找主窗口。  
- **右键托盘图标**打开菜单。  
- 关闭对话框 ≠ 退出；退出请用菜单「退出程序」。

## 2. 通用概念

### 2.1 任务饼图（非番茄）

| 进度 | 外观 |
|------|------|
| 0% | 半透明色圆 + 描边 |
| 10%～90% | 同色实心扇形填充 |
| 100% | 实心满圆 |

| 优先级 | 颜色 |
|--------|------|
| 高 | 红（**无**绿点） |
| 中 | 黄 |
| 低 | 绿 |

### 2.2 番茄钟图标

- 与菜单 🍅 同语义：**红果 + 绿萼**。  
- 果体随专注进度饼状填充（已消耗时间比例）。  
- 右侧文字：设置中可选 **倒计时** 或 **自定义文案**。

### 2.3 标题前缀

- 分类：成对括号包住 `一级-二级`，如 `[工作-需求]`。  
- 逾期：可配置前缀如 `【已逾期】`。

### 2.4 数据目录

| 系统 | 路径 |
|------|------|
| Linux | `~/.local/share/ZenTray/` |
| Windows | `%APPDATA%\ZenTray\` |
| macOS | `~/Library/Application Support/ZenTray/` |

主要：`active_tasks.json`、`settings.json`、`periodic_templates.json`、`archive/`、`reviews/`、`icons/`、`plugins/`（用户插件）、`ops_runs/`（脚本运行日志）、`zentray.log`。

## 3. Linux

### 安装前

- [ ] amd64 桌面环境  
- [ ] 建议：AppIndicator（`gir1.2-ayatanaappindicator3-0.1`、`python3-gi`）  
- [ ] 可选：`libnotify-bin`

### 安装

```bash
sudo apt install -y ./zentray_*_amd64.deb
zentray
```

### 注意

- 仅图标无文字：安装/启用 AppIndicator 支持。  
- 再点桌面图标：只刷新托盘，不新开进程。  
- Wayland 下热键可能不可用，请用托盘菜单。

2. 在通知区域找到托盘图标（可固定到任务栏旁）。  
3. 右键打开菜单。

## 6. 日常使用

### 启动节奏

1. 刚启动：仅应用图标。  
2. 片刻后：饼图 + 任务标题轮播。

### 任务

- 菜单：新建 / 任务列表 / 更新进度 / 编辑。  
- 进度仅 **10%** 步进。  
- 快捷键闪电添加：Linux/Win `Ctrl+Alt+T`。  
- **关联插件**（需先启用「脚本与服务」）：新建/编辑时可选择插件；在 **编辑任务** 或 **更新进度** 页可一键运行关联插件（进度见托盘）。

### 番茄钟

1. 菜单「🍅 专注 N 分钟」。  
2. 顶栏左：番茄饼图进度；右：倒计时或文案（见设置）。  
3. 可延长 / 中止。

### AI

- **每日计划 / 每日复盘** 在设置中分别开关与设定时间（到点或之后会补跑一次/天；改时刻后按新时间可再触发）。  
- 菜单「立即 AI 复盘」可手动跑复盘。  
- 多 API 配置时，**只能启用一个**。  
- 调度状态记在数据目录 `ai_schedule_state.json`（勿手改除非排查问题）。

### 脚本与服务

见 [第 8 节](#8-脚本与服务插件)。默认关闭，需在设置中启用。

### 退出

托盘菜单 → 退出程序。

## 7. 设置

左侧导航：

| 页 | 内容 |
|----|------|
| **AI 与通知** | 模型接入、每日计划、每日复盘、通知渠道 |
| **任务轮播** | 各优先级停留秒数、模式；逾期轮播与前缀 |
| **番茄钟** | 时长、延长；托盘右侧显示倒计时/文案 |
| **脚本与服务** | 总开关、内置/用户插件、插件目录、执行前确认 |
| **分类** | 一二级增删改；括号成对选择 |
| **外观** | 浅色 / 深色 / 跟随系统 |

通知渠道固定为 **应用弹窗** 与 **WxPusher**（不可自增删，可开关）。

## 8. 脚本与服务（插件）

### 8.1 开启

1. 托盘菜单 → **设置** → **脚本与服务**。  
2. 打开 **启用脚本与服务**。  
3. 保存。菜单顶部出现 **🧩 脚本与服务**。

可选：

- 加载内置插件 / 用户插件  
- 用户插件目录（留空则使用数据目录下的 `plugins/`）  
- 执行前确认（建议保持开启）

### 8.2 安装插件

1. 按 [插件规范](plugins/PLUGIN_SPEC.md) 准备目录（必有 `plugin.yaml` 与可执行 `entry`）。  
2. （开发者）校验：`python scripts/validate_plugin.py /path/to/plugin`  
3. 复制到用户插件目录，例如 Linux：

```bash
mkdir -p ~/.local/share/ZenTray/plugins
cp -a /path/to/my-plugin ~/.local/share/ZenTray/plugins/
```

4. 保存设置或重启 ZenTray。校验失败的插件**不会**出现在菜单。

### 8.3 运行

| 类型 | 菜单行为 | 顶栏 |
|------|----------|------|
| **脚本** | 点名称运行 | 进度文案（`⚡ …`）**暂时替代**任务轮播；结束后恢复 |
| **服务** | 启动 / 停止 / 状态 | 短提示，不长期占用轮播 |

- 脚本运行中不能开番茄钟；番茄进行中不能跑脚本。  
- 菜单「📄 上次运行日志」可打开最近一次完整日志（若存在）。  
- 日志目录：数据目录下 `ops_runs/`。

### 8.4 内置示例：网络清理

若开启 **加载内置插件**，菜单中可有 **网络清理（示例）**（`net-cleanup`）：

- 尝试刷新 DNS（`resolvectl` / `systemd-resolve`）  
- 尝试刷新 nscd、路由缓存（无权限则跳过并记日志）  
- 打印当前代理相关环境变量（不修改）  

**不会**自动断开 VPN 或改 Clash 配置。完整说明见仓库 `bundled_plugins/net-cleanup/README.md`。

### 8.5 与业务的关系

VPN 切换、邮箱相关等**具体操作**由你自己的插件实现；应用只负责发现、校验与展示进度。可复制 `net-cleanup` 目录改 `id`/`run.sh` 作为模板。

## 10. 故障排查

| 问题 | 处理 |
|------|------|
| 以为没启动 | 查顶栏/托盘与 `zentray.log` |
| 高优先饼图有绿点 | 已修复；可删 `icons/.pie_icons_version` 后重启重生图标 |
| 番茄不像番茄 | 同上重生 `tomato_*.png`；确认在专注状态 |
| 设置页是旧的 | 确认已 `npm run build` 且未设 `ZENTRAY_UI=qt` |
| 无顶栏文字 | Linux 安装 AppIndicator 支持 |
| 菜单没有「脚本与服务」 | 设置中启用；保存后看菜单顶部 |
| 插件不出现 | `validate_plugin.py` 是否通过；`entry` 是否 `chmod +x`；是否在正确 plugins 目录 |
| 脚本跑完轮播不恢复 | 看 `zentray.log`；确认进程已退出 |
| 每日计划/复盘没到点 | 确认已启用且 API Key 有效；看日志「触发每日计划/复盘」；过点会补跑；改时刻后需等新时间 |
| 计划只在约 8 点跑 | 旧版仅匹配整点小时且内存记「今日已跑」；升级后看设置里的调度时间是否保存成功（输入时间后点保存） |

```bash
# 强制重生托盘图标
rm -f ~/.local/share/ZenTray/icons/.pie_icons_version
# 然后重启 zentray
```
